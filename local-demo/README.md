# اجرای محلی سایت (دمو)

این پوشه سایت ژورنال را با **محتوای نمونه** روی کامپیوتر خودتان اجرا می‌کند. تنها چیزی که لازم دارید **Docker** است و به Node یا PHP نیازی نیست.

> همه‌ی مقاله‌ها، نویسنده‌ها، اعضای هیئت تحریریه و نام ژورنال **ساختگی** هستند و فقط برای نمایش طراحی ساخته شده‌اند.

## پیش‌نیازها

- **Docker Desktop** (ویندوز یا مک) یا Docker Engine (لینوکس)، روشن و در حال اجرا
- حدود **۴ گیگابایت** فضای خالی
- پورت‌های **8080** و **8025** آزاد باشند

## اجرا

**مک / لینوکس** (داخل ترمینال، در پوشه‌ی `local-demo`):

```bash
./start.sh
```

**ویندوز** (داخل PowerShell، در پوشه‌ی `local-demo`):

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

بار اول چند دقیقه طول می‌کشد، چون ایمیج OJS (حدود ۱ گیگابایت) دانلود می‌شود. بعد از آن آدرس‌ها چاپ می‌شوند.

## آدرس‌ها و حساب‌ها

| چه چیزی | آدرس |
|---|---|
| سایت | <http://localhost:8080/djas> |
| مقاله با متن کامل و رفرنس‌های کلیک‌شو | <http://localhost:8080/djas/article/view/5> |
| فهرست نویسندگان | <http://localhost:8080/djas/authors> |
| هیئت تحریریه | <http://localhost:8080/djas/about/editorialMasthead> |
| ورود مدیر (پنل ادمین) | <http://localhost:8080/index/login>، نام کاربری `admin`، رمز `admin-dev-Password1` |
| ایمیل‌های تستی (همه‌ی ایمیل‌های سایت اینجا جمع می‌شوند) | <http://localhost:8025> |

برای دیدن **پنل نویسنده**: از منوی بالای سایت *Register* بزنید و یک حساب بسازید، بعد *Submit a Manuscript* را بزنید. نقش نویسنده و داشبورد *My Submissions* خودکار فعال می‌شود. در *Profile › Public* می‌توانید عکس، بیوگرافی و وب‌سایت را وارد کنید.

## توقف و ریست

| کار | مک / لینوکس | ویندوز |
|---|---|---|
| توقف (داده‌ها می‌مانند) | `./stop.sh` | `.\stop.ps1` |
| برگشت به دموی اولیه (همه‌ی تغییرات پاک می‌شود) | `./reset.sh` | `.\reset.ps1` |

## اگر دانلود ایمیج‌ها از Docker Hub خطا داد

Docker Hub برای IPهای ایران محدود است. یکی از این دو راه:

1. **میرور رجیستری:** در Docker Desktop به *Settings › Docker Engine* بروید و آدرس یک میرور داخلی را در `registry-mirrors` بگذارید، مثلاً:

   ```json
   { "registry-mirrors": ["https://docker.arvancloud.ir"] }
   ```

   *Apply & restart* را بزنید و دوباره `start` را اجرا کنید. آدرس میرورها گاهی عوض می‌شود؛ اگر این یکی کار نکرد، یک میرور فعال دیگر را امتحان کنید.
2. **VPN:** با VPN روشن `start` را اجرا کنید. بعد از اولین دانلود، دیگر به اینترنت نیازی نیست.

## محتویات این پوشه

- `snapshot/`: دیتابیس و فایل‌های دموی آماده (خروجی `dev/export-snapshot.sh`)
- `start` / `stop` / `reset`: اسکریپت‌های اجرا
- اسکریپت‌ها از همان فایل `deploy/docker-compose.dev.yml` پروژه استفاده می‌کنند. قالب **Meridian** و پلاگین‌ها مستقیم از پوشه‌ی `plugins/` خوانده می‌شوند، پس هر تغییری در کد بعد از رفرش صفحه دیده می‌شود. اگر تغییری دیده نشد، کش را پاک کنید: پنل ادمین › *Administration › Clear Template Cache*.
